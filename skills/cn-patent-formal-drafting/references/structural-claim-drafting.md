# 结构类专利起草规则

当 `claim-type-classification.md` 判定为结构类，或方法/系统方案中包含实体部件、装配关系、运动关系、空间关系时读取本文件。

结构主导混合方案也读取本文件。若创造性主要来自机械、光学、电气或其他实体结构的部件组合及相对关系，即使同时包含设备、装配方法、控制方法、检测方法、处理器或介质权利要求，也应以结构类为主，不转入方法类或系统/装置类模板。

## 适用范围与锚样稿

本文件以 CN117336591A（摄像头模组和电子设备）作为结构类锚样稿，覆盖结构主导发明中部件组合 + 空间关系 + 连接关系 + 运动关系类的常见情形，含设备/整机配套保护。区别特征落在部件配合关系 / 空间投影 / 连接方式 / 运动约束 / 装配次序之一时按本文件起草。

锚样稿的角色是**气质学习材料**，不是模板照抄表。verbatim 例句用于锚定"通用规律 → 真实写法"的映射；具体发明的部件命名、关系组合、必要约束应按本发明的技术内容重新归并，不得抄录样稿命名（如「电路板 / 驱动装置」、「马达动件 / 马达定件」等）。

不适用：
- 方法主导方案 → [method-claim-drafting.md](method-claim-drafting.md)
- 多主体协议方案 → [method-claim-drafting.md](method-claim-drafting.md) §多主体方法
- 纯界面交互方案 → 不在本 skill 处理范围

阅读顺序（建议）：§独权骨架 → §从权梯队 → §红线 → §权要句式库 → §摘要 → §说明书各段 → §实施方式句式库。每段都给「骨架 + verbatim 例句 + 要点 + 禁项」四部分；verbatim 例句皆引 CN117336591A，撰写时按句式选用，不套用任何泛化占位框架（占位符如 `【第一部件】【第二部件】【位置】` 出现即视为不合格）。

## 独权骨架

主题命名：`一种 + 发明名称`（发明名称为名词性短语，标注附图标号，如「摄像头模组(10)」「驱动装置(2)」「电路板(1)」）。

骨架行：`一种{发明名称}({标号})，其特征在于，包括：` 后接 2-4 个核心部件块，分号分隔；末段为装配关系约束句，句号收尾。

CN117336591A 实证（权 1）：
- 2 个核心部件块 = 电路板(1)（含活动板件/固定板件/柔性连接结构 3 子部件 + 空间关系）+ 驱动装置(2)（含马达动件/马达定件/驱动马达 3 子部件 + 层叠关系 + 一体化约束）
- 1 段装配关系约束句 = 倒置堆叠 + 马达定件-固定板件固定连接 + 马达动件-活动板件固定连接

部件块结构与子部件级别：

| 部件块位 | 子部件级别 | CN117336591A 权 1 实证 |
|---|---|---|
| 承载主体部件 | 包含活动子部件 + 固定子部件 + 连接子部件 | 电路板(1)：活动板件(11) + 固定板件(13) + 柔性连接结构(12) |
| 功能主体部件 | 包含动件 + 定件 + 驱动子部件，强调层叠 / 一体化约束 | 驱动装置(2)：马达动件(23) + 马达定件(21) + 驱动马达(22) |
| 装配关系约束句 | 顶层装配方式 + 相对位置 + 关键固定连接 | 倒置堆叠 + 位于图像传感器外围 + 马达定件/固定板件固定连接 + 马达动件/活动板件固定连接 |

部件块数硬约束：2-4 个；< 2 个独权过抽象、保护边界不清（"包括一个部件"等同于无限定）；> 4 个独权过肥、违反独权肥度红线 R1。

子部件级别硬约束：每个部件块的子部件展开不超过 3 层（部件 → 子部件 → 子子部件）。CN117336591A 权 1 实证最多 2 层：驱动装置 → 马达定件 → 固定顶板 / 固定侧框。

附图标号约束（独权专有）：独权内每个核心部件、子部件首次出现时**必须**括号附标号，与说明书附图保持一致。CN117336591A 权 1 verbatim：`电路板(1)`、`活动板件(11)`、`固定板件(13)`、`柔性连接结构(12)`、`图像传感器(5)`、`间隔空间(14)`、`驱动装置(2)`、`马达动件(23)`、`马达定件(21)`、`驱动马达(22)`、`固定顶板(213)`、`固定侧框(214)`、`摄像头模组(10)` 全部带标号。

## 红线

独权肥度防线 7 条（R1-R7），均针对**结构独权**（整机配套保护权要按 §从权梯队 S6 末档骨架处理，不在本段单列红线）。任一违反 → 必须下放从权 / 实施方式 / 分案。

R1 独权部件块数 ≤ 4。CN117336591A 权 1 为 2 块（电路板 + 驱动装置）+ 1 段装配关系约束句；超过 4 块 → 早绑实现风险，把工程粒度强行抬到独权层级。

R2 独权内不嵌：具体材料 / 优选尺寸数值 / 制造工艺步骤。CN117336591A 权 1 不写「电路板为 FR-4 材质」「驱动马达直径为 2 mm」「采用 SMT 表贴工艺」等具体材料 / 尺寸 / 工艺；这些进 S1 / S2 从权或具体实施方式。

R3 独权内不嵌：装配次序号 / 步骤号（"第一步、第二步、S1、S2、步骤一"等）。结构权要保护结构形态而非装配过程；装配次序进具体实施方式段。

R4 独权内不嵌：商品名 / 厂商命名 / 型号（"XX 品牌马达""ABC 公司 SMA 线"等）。CN117336591A 权 1 用通用结构命名「驱动马达」「SMA 线」（权 7-8 才出现），不绑定具体供应商或型号。

R5 独权内不嵌：优选参数范围 / 具体数值范围（"曲率半径为 X-Y mm""夹角为 30-60 度""K 值为 60-80 mN/mm"等）。CN117336591A 权 1 无 `Kx/Ky/Rz` 具体取值（权 1 无优选参数；具体数值「Kx=68.7、Ky=70.8、Rz=67.4 mN/mm」在说明书 B2 段出现）。

R6 独权内不嵌：整机模块名（"主板""电池模组""显示屏""壳体""边框"等非本发明结构的整机组件）。CN117336591A 权 1 主题为「摄像头模组」，权 1 内不出现「主板」「电池」「显示屏」等整机组件；整机集成关系进权 15 整机配套保护。

R7 独权内不嵌：替代结构展开（"或者为 A 形态、或者为 B 形态"等）。结构独权应限定唯一的部件 + 关系框架；替代结构 / 替代部件 / 替代装配方式必须下放 S4 / S5 从权。CN117336591A 权 7 与权 8 分别用 S4 句式给出"两驱动单元 + SMA + 放大结构"和"四 SMA + 四放大机构"两种替代设计，两条独立从权而非独权内分支展开。

## 权要句式库

6 类结构类权要句式（S1-S6）。骨架 + verbatim 例句 + 要点 + 禁项四段格式；例句皆引 CN117336591A。

#### S1 部件细节连接

骨架：`所述{部件}{连接动词}于{位置/对象}` 或 `所述{部件}和{对象}通过{方式}{动词}`。

例句（CN117336591A 权 2）：

> 所述马达动件(23)和所述活动板件(11)通过胶层固定。

要点：连接动词反映约束类型（设置 / 连接 / 固定 / 紧固 / 卡接 / 焊接 / 粘接 / 转动连接 / 滑动连接 / 可拆卸连接）；同一部件在权要内连接动词保持一致；首次出现的部件附标号。

禁项：用「优选地通过胶层固定」（"优选"是专利忌用词）；用「比如 / 例如」引出连接方式（这些是 B2 实施方式句式）；省略附图标号。

#### S2 部件层级扩展

骨架：`所述{部件}还包括{子 A}和{子 B}，所述{子 A}{动作/作用}，所述{子 B}{动作/作用}`。

例句（CN117336591A 权 3）：

> 所述驱动装置(2)还包括磁石(24)和接触件(25)，所述磁石(24)和所述接触件(25)组装至所述固定顶板(213)，所述磁石(24)用于向所述马达动件(23)提供磁吸力，在所述磁吸力的作用下，所述马达动件(23)和所述接触件(25)接触。

要点：用「**还包括**」引出新增子部件；「所述 X 用于 Y」描述子部件的功能 / 作用；条件触发用「在 X 的作用下」（与 method 侧 A2「在 X 成立时」呼应，但作用主语是物理力 / 状态而非逻辑判断）；新增的子部件首次出现附标号。

禁项：用「其中具有 / 其中含有」替代「还包括」；用「为了 X / 以使 X」描述作用（应改「用于 X / 在 X 作用下」）；用「在通电后…」「在使用时…」抽象状态描述代替具体物理触发（应改"在所述磁吸力的作用下"等具体力 / 场 / 状态）。

#### S3 空间关系 / 接触类型

骨架：`所述{部件 A}与所述{部件 B}{空间/接触关系}` 或 `所述{部件 A}和{部件 B}之间{形成/具有}{关系/缝隙}`。

例句（CN117336591A 权 5）：

> 所述接触件(25)包括球面，所述球面用于和所述马达动件(23)的表面接触，所述球面和所述马达动件(23)之间为点接触。

例句（CN117336591A 权 6）：

> 所述摄像头模组(10)包括加强板(7)和固定在所述加强板(7)上的缓冲结构(71)，所述加强板(7)位于所述电路板(1)的底面的一侧，所述加强板(7)的边缘和所述固定板件(13)固定连接，所述缓冲结构(71)位于所述加强板(7)的朝向所述活动板件(11)的表面，在所述马达动件(23)和所述接触件(25)接触的状态下，所述活动板件(11)和所述缓冲结构(71)之间形成间隔缝隙。

要点：空间关系优先用几何术语（相对设置 / 平行 / 垂直 / 同轴 / 偏置 / 在投影方向上重叠 / 错位 / 间隔缝隙 / 点接触 / 面接触）；具体尺寸数值不入独权（下放 S4 从权或具体实施方式）；条件触发用「在 X 的状态下」展开关系存续条件。

禁项：用「大约 / 大概 / 约 / 近似」修饰几何关系（应给精确几何术语）；空间关系跟连接动词混用（如"垂直连接"应拆为"垂直 + 固定连接"两层关系）；条件触发用「当…时…」（结构类用「在 X 的状态下」更地道，与 CN117336591A 一致）。

#### S4 具体设计方案

骨架：长展开式 `所述{部件}包括{N 个子组件}，所述{子组件 i}包括{细节 j}，所述{细节 j}{动作/连接}{对象}` —— 每段一组子组件 + 细节展开 + 连接关系。

例句（CN117336591A 权 7 节选）：

> 所述驱动马达(22)包括两个驱动单元(221)，所述两个驱动单元(221)分别设置在所述图像传感器(5)的一对对角位置的外围，各所述驱动单元(221)包括第一SMA线(2211)、第二SMA线(2212)、固定部(2213)、第一放大结构(2214)和第二放大结构(2215)，所述第一SMA线(2211)和所述第二SMA线(2212)相互垂直，所述第一SMA线(2211)的第一端(1E1)和所述第二SMA线(2212)的第一端(2E1)均固定连接所述马达定件(21)，所述第一SMA线(2211)的第二端(1E2)固定连接所述第一放大结构(2214)的第一活动部(4M1)...

要点：先给"包括 N 个子组件"声明结构基线，再用"各所述 X 包括..."逐层展开；同一权要内子组件命名一致；子组件的端点 / 活动部首次出现附标号；连接关系用具体的"固定连接 / 焊接固定 / 一体成型"等动词，不模糊（如"连着 / 接着 / 相连"）。

禁项：用「比如包括 / 大约包括」引出子组件（应直接「包括」）；子组件命名前后不一致（如先称"驱动单元"后改"驱动模块"）；连接关系不收敛在权要末尾形成完整闭环（应每条 SMA / 放大结构 / 固定部 / 活动部都有连接对象）；展开层次超过 4 层（驱动马达 → 驱动单元 → SMA 线 → 第一端 / 第二端，4 层是 CN117336591A 实证上限）。

#### S5 整体布局 / 拓扑

骨架：`所述{核心部件}包括{N 部分}，所述{部分}分别{位置/作用}` —— 描述部件的整体拓扑（对角分布、对称布局、四角分布、N 重组合）。

例句（CN117336591A 权 9）：

> 所述图像传感器(5)包括四个角，所述四个角分别构成所述图像传感器(5)的两对对角位置，所述柔性连接结构(12)分布在所述图像传感器(5)的一对所述对角位置的外围，所述驱动马达(22)包括两个驱动单元(221)，所述两个驱动单元(221)分别设置在所述图像传感器(5)的另一对所述对角位置的外围。

要点：用"两对对角位置 / 四条边 / N 重对称"描述拓扑骨架；"分别"引出多个独立位置的对应关系；同一权要内一组对应关系不交叉（如"一对对角位置外围"和"另一对对角位置外围"必须互斥不重叠）；几何位置用相对术语（外围 / 内侧 / 顶面 / 底面 / 端面），不用绝对坐标（不写 "X=0, Y=10"）。

禁项：用「左右两边 / 上下两面 / 前后两侧」非中性术语（应改"一对相对边 / 一对相对面"）；用顿号或逗号代替"分别"做多对应分发；省略附图标号；用"基本上对称 / 大致分布"模糊修饰。

#### S6 整机配套保护（末档）

骨架：`一种{整机/设备}({标号})，其特征在于，包括{处理单元/控制单元}({标号})和如权利要求 {1-N} 任一项所述的{结构主题}({标号})，所述{处理单元}与所述{结构主题}{电连接/通信连接}，所述{处理单元}用于{功能}`。

例句（CN117336591A 权 15）：

> 一种电子设备(1000)，其特征在于，包括处理器(600)和如权利要求1‑14任一项所述的摄像头模组(10)，所述处理器(600)与所述摄像头模组(10)电连接，所述处理器(600)用于对所述图像传感器(5)输出的图像信号进行处理。

要点：整机主题用「电子设备 / 系统 / 终端 / 装置」（带附图标号）；用「包括 X 和如权利要求 N-M 任一项所述的 Y」单引方法权要的全部技术内容，不重复展开结构内部；接口连接动词具体（电连接 / 信号连接 / 总线连接），不用"连着"；接口部件功能用一句话收尾（"所述 X 用于 Y"），不展开 Y 的实现细节。

禁项：用「包括上述结构」（应改「如权利要求 N-M 任一项所述的{结构主题}」）；整机权要扩展结构权要未覆盖的技术细节；接口部件（处理器 / 控制器）的功能展开过深（"所述处理器用于：首先对图像信号进行 A 处理；然后进行 B 处理"——这是方法权要写法，不进结构类整机配套）；缺失接口连接动词；附图标号缺失。

## 摘要

摘要回答四问：发明属于什么结构 / 由哪些核心部件构成、关键空间关系或装配关系、达到什么效果。文字部分不得超过 300 字。

骨架行：`本申请公开{发明名称}。{结构主题}包括{部件 1}和{部件 2}。{关键空间/连接关系}。本申请提供一种可以{效果回扣}` —— 短句串接，效果回扣紧贴背景技术缺陷句。

例句（CN117336591A 摘要 verbatim 节选）：

> 本申请公开一种摄像头模组及电子设备。摄像头模组包括电路板和驱动装置。电路板包括活动板件、固定板件和柔性连接结构，活动板件用于承载图像传感器，固定板件位于活动板件的外围且二者间隔空间，柔性连接结构位于间隔空间且连接在活动板件和固定板件之间。驱动装置包括马达动件、马达定件和驱动马达，沿摄像头模组的光轴方向，马达动件、驱动马达和马达定件的固定顶板依次层叠设置，驱动马达连接在马达定件和马达动件之间。驱动装置倒置堆叠在电路板的顶面且位于图像传感器的外围，马达定件和固定板件固定连接，马达动件和活动板件固定连接。本申请提供一种可以实现摄像头模组小型化，节约电子设备内部空间及实现电子设备薄型化设计。

要点：以「本申请公开」领起；摘要中**不带附图标号**（附图标号只在权要书与说明书出现）；部件列表与独权 A 段骨架同步、核心关系与独权 verbatim 措辞一致；摘要末以「本申请提供一种可以...」短句给出效果回扣（与背景技术缺陷句呼应）；摘要末不列从权细节 / 参数 / 公式 / 阈值。

禁项：用「本发明属于【技术领域】，公开了一种【发明名称】」开头（占位骨架）；摘要中带附图标号（如「电路板(1)」）—— 标号是权要书与说明书的专有；用「显著 / 大幅 / 完美 / 革命性」夸张词；超过 300 字；列从权梯队（从权应只在权利要求书与说明书出现）；只写部件不写关系（"摄像头模组包括电路板和驱动装置" 后必须紧跟空间/连接关系展开）。

## 说明书

### 背景技术

背景技术建立现有结构的问题场景，不提前介绍本发明结构方案。

骨架（3 段）：

1. 技术领域 + 现有技术原理（定义关键术语，给出现有方案的工作原理 / 物理机制）
2. 现有方案的应用场景与典型实现（指明现有方案在哪些场景下使用、采用了什么技术路径）
3. 共性矛盾与缺陷（在小型化 / 集成度 / 可靠性 / 装配复杂度 / 成本之一上的瓶颈，且能直接对应发明内容要解决的问题）

例句（CN117336591A 背景技术 verbatim 节选）：

> 光学防抖技术(OIS)，其原理是在陀螺仪侦测到微小的移动，会将信号传至微处理器立即计算需要补偿的位移量，然后通过补偿镜片组或传感器，根据镜头的抖动方向及位移量加以补偿，从而有效的克服因相机的振动产生的影像模糊。光学防抖技术区分为传感器防抖(Sensor shift)与镜头防抖(Lens shift)两种。

> 对于传感器防抖(Sensor shift)技术而言，通过驱动装置带动图像传感器移动，可以调节图像传感器的具体的位置和姿态，实现摄像头模组的防抖功能。在电子设备的轻薄化及多功能的发展趋势下，摄像模组的设计过程中，针对图像传感器的驱动装置，如何设计可以实现摄像头模组小型化，节约电子设备内部空间及实现电子设备薄型化设计，为业界持续探索的课题。

要点：定义术语时给中英文对照与简称（如 OIS / Sensor shift / Lens shift）；现有方案先指原理再描分类；用"在…的发展趋势下…如何设计…为业界持续探索的课题"语句结构暗示矛盾，**不**用编号"第一、第二、第三"罗列；缺陷暗示与发明内容要解决的问题一致性闭环。

禁项：「自【技术名称】出现以来…」泛化开头；「第一，【问题 1】；第二，【问题 2】；第三，【问题 3】」编号罗列（破坏问题间的因果链，CN117336591A 不编号）；提前出现"本发明 / 本申请实施例"字样（背景技术不介绍发明方案）；现有方案描述过弱或失真；只罗列文献不抽象共性矛盾；堆参数公式（参数 / 公式进发明内容或实施方式）。

禁项：用"在另一种实施方式中"做"### 小标题"切分（小标题切分留给独立实施例）；用"优选"表达替代关系；省略"一种实施方式中"开头。

#### B4 可选实施方式 / 第二实施方式段（独立实施例切分）

骨架：第二实施方式 / 第三实施方式作为独立段或独立子段，与第一实施方式区别清楚（不同核心部件 / 不同关系），结构内部按 B1-B3 组织。

#### B5 效果回扣段

骨架：`本方案通过{核心结构特征}，{中间机理}，有利于{解决的问题 / 避免的缺陷}` 或 `本申请实施例通过{核心结构特征}，{中间机理}，从而有助于{效果}`。

例句（CN117336591A §具体实施方式 行 217 末段）：

> 本申请实施例通过将驱动装置形成一体式的组装结构，形成驱动装置的模组化结构设计，具有结构紧凑的优势，有利于实现驱动装置的整体尺寸小型化的设计。而且通过倒置堆叠的组装方式将驱动装置组装在电路板的顶面，利用电路板的顶面一侧的空间布置驱动装置，能够有效利用摄像头模组的有效焦距(EFL)所需要的空间，有利于减少摄像头模组Z向(即光轴P延伸的方向)尺寸。

要点：以"本方案 / 本申请实施例"领起；复述核心结构特征 + 中间机理 + 与背景技术呼应的"解决的问题 / 避免的缺陷"；可用"使得 / 从而 / 有利于 / 这样"连接因果；技术效果分项展开（小型化、紧凑、降低功耗等），与发明内容效果段对齐。

禁项：用"显著 / 大幅 / 完美 / 革命性 / 突破性 / 极大"等夸张词；用"优于现有所有方法 / 优于本领域所有方案"绝对化对比；省略对背景技术问题的呼应（效果回扣脱节）；只写效果不写产生效果的具体结构。
