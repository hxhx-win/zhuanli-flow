# 中文专利语言风格差例 / 好例对照（审稿必读，起草按需）

本指南列出 R1-R7 各条硬规则的差例（A 风格）与好例（B 风格）对照，作为重写参照。R1-R7 的硬规则本体在 `language-style-rules.md`（起草必读）。

审稿 subagent 必读本文件，逐条对照命中规则的差例特征。起草 subagent 仅在自检命中违规时取片段读取。

差例（A 风格）取自慢动作实况照片帧管理 v2 提交稿，好例（B 风格）参照 CN112135129A 已授权稿撰写惯例改写。

## R1 差例 / 好例

**差例（A 原文，独权 1 拍摄阶段切换段落）**：

> 响应于拍摄事件,所述帧管理实例由所述预录阶段原子切换至所述拍摄阶段,并在切换瞬间执行接缝缝合,所述接缝缝合包括:取出所述预录阶段尚未落盘的最后一帧并以一个目标帧周期作为该最后一帧的呈现时长后落盘提交;以所述最后一帧的呈现时间戳与所述呈现时长之和作为拍摄阶段重基基准;将所述重基基准向前减去一个所述目标帧周期,得到调整后基准,作为所述拍摄阶段的重建起点;

**好例（B 风格重写）**：

> 在所述帧管理实例接收到拍摄事件的情况下，由预录阶段切换至拍摄阶段，并在切换时执行下述步骤：
> 取出预录阶段尚未落盘的最后一帧；
> 以一个目标帧周期为所述最后一帧的呈现时长，将所述最后一帧落盘提交；
> 以所述最后一帧的呈现时间戳与所述呈现时长之和，确定为拍摄阶段重基基准；
> 将所述拍摄阶段重基基准减去一个目标帧周期，得到调整后基准；

## R2 差例 / 好例

**差例**：A 独权直接写 `执行接缝缝合，所述接缝缝合包括…`，权要内未对"接缝缝合"加引号或括注，仅在条文后展开三步。

**好例**：

> 在切换时执行接缝处理（以下简称接缝处理；所述接缝处理由"末帧封口、重基基准推导、首帧基准预减"三步组成）：…

或更彻底地不造词：

> 在切换时执行下述三个步骤：
> 第一步，将预录阶段尚未落盘的最后一帧落盘提交；
> 第二步，根据所述最后一帧的呈现时间戳与呈现时长，确定拍摄阶段重基基准；
> 第三步，根据所述拍摄阶段重基基准与一个目标帧周期，确定调整后基准。

### A 稿自造词清单（首现处必须加括注或改为标准说法）

| A 自造词 | 处理建议 |
|---|---|
| 接缝缝合 | 改为"接缝处理"+ 括注三步；或彻底拆为三步 |
| 重基基准 / 调整后基准 | 保留但首现加括注（"重基基准（即拍摄阶段时间轴起点）"） |
| 阶段回退 | 改为"切换回预录阶段" |
| 空缓存兜底 | 改为"在所述待落盘缓存为空的情况下" |
| 延迟一帧封口 | 首现加括注（"延迟一帧封口（即接受当前帧不立即落盘，待下一帧到达时为前一帧补齐呈现时长后落盘）"） |
| 阶段化帧控 | 改为"按阶段差异化的丢帧条件" |
| 动作描述结构 | 改为"运动信息描述符" 或行业标准词 |

## R3 差例 / 好例

**差例**（A 独权 1 末段）：

> 在所述拍摄阶段,以所述调整后基准为起点,按所述目标帧率对源端视频帧等步长重建呈现时间戳,使所述拍摄阶段的首帧重建后的呈现时间戳等于所述重基基准、且后续帧按所述目标帧率等步长向后展开,**以使输出端按所述目标帧率播放时呈现慢动作**;

**好例**：

> 在所述拍摄阶段，根据所述调整后基准与所述目标帧率，对源端视频帧重建呈现时间戳，使得所述拍摄阶段的首帧的重建呈现时间戳等于所述重基基准。

`以使输出端按所述目标帧率播放时呈现慢动作` 整段挪入发明内容段或有益效果段。

## R4 差例 / 好例

**差例**（A 发明内容段，原文）：

> 上述第一方面至第八方面共同构成本发明的整体技术方案。所述预录阶段的抽帧与等步长呈现时间戳重建、所述接缝缝合、所述拍摄阶段的等步长呈现时间戳重建、以及所述切换回预录阶段并清空阶段内状态四者**相互依赖、不可分割**：…**本领域技术人员据此应认识到，本发明的整体技术方案不能被分解为现有技术中分别已知的"循环缓冲"加"运动检测自动慢动作"或者"播放端慢放"等单点手段的简单组合**。

**好例**：

> 上述各方面共同实现以下技术效果：预录阶段的等步长呈现时间戳重建为接缝处理提供了起点；接缝处理为拍摄阶段的呈现时间戳重建确定了基准；切换回预录阶段并清空阶段内状态使所述帧管理实例能够支持多段连拍。各方面相互配合，协同实现预录段与拍摄段在同一时间轴上的连续衔接。

## R6 差例 / 好例

## R7 差例 / 好例

**差例**（A 原文）：

> 需要特别说明,步骤 S6 中的所述预减一个目标帧周期是**本实施例的核心精细时序设计之一**。…**本设计避免了"以代码中常规自增方式实现的重建公式"在直接套用 X 作为首帧基准时所产生的偏移,而非可由本领域技术人员直接想到的工程惯例。**

**好例**：

> 步骤 S6 中所述将拍摄阶段重基基准减去一个目标帧周期，使后续步骤 S7 中重建呈现时间戳的公式（公式 X）在 n=1 时所得的首帧呈现时间戳等于所述拍摄阶段重基基准。在不进行该减法的情况下，n=1 时所得的首帧呈现时间戳为所述拍摄阶段重基基准与所述目标帧周期之和，从而在时间轴上相对所述拍摄阶段重基基准存在一个目标帧周期的偏移。
