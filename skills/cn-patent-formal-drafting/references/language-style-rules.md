# 中文专利语言风格硬规则（B 风格基线 — 起草必读）

本指南列出权利要求书与说明书发明内容 / 具体实施方式段的 7 条硬规则。起草前必须逐条对照；违反任意一条即必须重写。差例 / 好例对照与重写示范见 `language-style-examples.md`（审稿必读，起草按需读取）。

---

## R1 句长与节奏：长句拆短，分号不超三层

- 权要单条特征句中，分号嵌套不超过两层；逗号一气到底超过 80 字必须拆。
- 多个并列动作 / 并列条件，使用分号 `；` 串联；分号之间每段独立可读。
- 不允许"一逗到底"的长句把多个特征捏在一处。

## R2 自造术语：首现处必须括注定义，能不造词就不造

- 自造词在权要内首次出现处必须以括号或冒号给出展开定义，并保持全文同名同义。
- 优先使用专利领域已有标准词；当现有术语足够时禁止自造。
- 同一概念在权要 / 发明内容 / 具体实施方式中必须用同一名称，不允许多种说法混用。

## R3 句式模板：被动八股，禁用目的性"以使…"

- 主句使用被动或主动均可，但禁止在权要中出现以下目的性、效果性短语：`以使…`、`从而…`、`以保证…`、`以支持…`、`避免…`、`以便…`。
- 效果与作用一律挪入说明书"发明内容"或"有益效果"段，权要只列纯特征。
- 推荐使用以下被动八股：
  - `在…的情况下，执行…`（替代 `响应于…`）
  - `所述 X 包括…，其中…`（替代 `所述 X 满足以下条件：…`）
  - `根据 X 和 Y，确定 Z`（替代 `以 X 和 Y 为基准得到 Z`）

## R4 八股程度：权要内禁止论证，禁用"不可分割"类自认

- 权要内只列特征，不允许出现下述论证语：`…相互依赖、不可分割`、`本发明的整体技术方案不能被分解为现有技术中…的简单组合`、`本领域技术人员据此应认识到…`。
- 发明内容段如需说明协同性，使用"协同实现 X 技术效果"，禁止"不可分割"自认窄陈述。
- 从权一律以 `根据权利要求 N 所述的方法/装置，其特征在于，…` 起头；不允许夹带"上述第 X 方面"等内部分编号。
- 装置侧从权必须与方法侧从权完全镜像，每条方法从权对应一条装置从权。

## R5 审查员友好：自造词必须可被精确检索

- 自造词、缩写在权要首次出现处加引号或括注。
- 缩写第一次出现时给出中英文双注：`MMVD（merge with motion vector difference，带运动矢量差的合并模式）`。
- 关键参数、阈值、模式标识首次出现处必须能直接被全文检索定位到唯一定义点。
- 公式中的每一个符号在公式所在权要或其紧邻段中必须给出文字定义；不得只在说明书中定义而权要中只出现符号。

## R6 段落与衔接：发明内容用"在一种可能的实施方式中"，禁"第 N 方面"散文体

- 发明内容段使用"基于第一方面，在一种可能的实施方式中，所述方法还包括…"模板，每个可能的实施方式与一项从权一一对应。
- 禁止"第一方面…第八方面…第八方面共同构成本发明的整体技术方案"这种自创结构。
- 段落编号采用国知局通用 `[0001]…[00xx]` 体例（导出阶段加），不在 markdown 源稿中手写第几方面。
- 现有技术段不写"第一类是…第二类是…第三类是…"散文式分类，改为"在一种现有技术中…在另一种现有技术中…"或直接逐段引证文献。

## R7 整体腔调：消除工程论文体，统一为代理模板腔

- 不允许第一人称"本发明"以外的"我们""本方法"等口语化表述。
- 不允许"本设计避免了…工程惯例""并非可由本领域技术人员直接想到的工程惯例"这类辩论体表述出现在说明书中；需要论证创造性时留给答审通知阶段。
- 实施例段落避免"需要特别说明""本设计的核心精细时序设计之一"等强调性表述。
- 数学公式必须以 OOXML `m:oMath` 嵌入，符号在首现处统一定义；不允许公式以图片粘贴或在文本中只剩"其中, 为…"。

## 起草前自检清单

起草任何一份正式稿前，按下表逐条自检；任何一项标 ✘ 必须修订到 ✓ 才允许进入下一阶段。

| # | 检查项 | 检查方法 |
|---|---|---|
| 1 | 权要单条无 80 字以上的"一逗到底" | 全文搜逗号密度，任一句逗号 ≥ 5 个且无分号需拆 |
| 2 | 权要内无目的性短语 | 搜 `以使`、`从而`、`以保证`、`以支持`、`避免` 在权要中出现的位置 |
| 3 | 权要内无论证 / 自认窄语 | 搜 `不可分割`、`本领域技术人员据此`、`不能被分解` |
| 4 | 自造词首现处加括注 | 列出全文自造词，逐个核对首现处定义 |
| 5 | 公式符号首现处定义齐全 | 列出所有符号，逐个核对在公式所在段是否有文字定义 |
| 6 | 装置侧从权与方法侧镜像 | 列方法从权 N 项 → 装置从权应有 N 项 → 一一对应 |
| 7 | 发明内容段无"第 N 方面"自创编号 | 全文搜 `第一方面`、`第二方面` 等 |
| 8 | 现有技术段无"第一类是…第二类是…"散文体 | 改为 `在一种现有技术中` 或直接列引证文献 |
| 9 | 公式以 m:oMath 渲染 | 导出 docx 后核对公式是否可见、可编辑 |
| 10 | 缩写中英文双注 | 列出全文缩写，逐个核对首现处 |

## 审稿核对要点（供 `cn-patent-attorney-review` 引用）

审稿时按 R1–R7 逐条扫描：

- 命中差例特征（如出现 `以使`、`不可分割`、`第一方面`）即标"高优先级修改意见"；
- 自造词未加括注、装置权与方法权不镜像即标"中优先级"；
- 公式渲染问题、缩写未双注即标"形式问题"。

差例 / 好例对照与重写示范见 `language-style-examples.md`；修改意见格式参照 `cn-patent-attorney-review/references/review-checklists.md` 的优先级体例。
